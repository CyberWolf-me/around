# Around — Security & Privacy Verification Checklist

| Requirement (CTO Mandate Section 5) | Database / RLS Enforcement (`supabase/`) | Client / Repository Enforcement (`lib/`) | Automated Test Coverage |
|---|---|---|---|
| **1. Unauthorized users cannot access friends-only Drops** | `posts_select_dual_layer` policy (`00002`) + `get_friends_feed` (`00003`/`00005`, `SECURITY INVOKER` using `auth.uid()`) | `PostsNotifier.getFriendsDrops` & `getDropsForPlace` (`lib/data/repositories/posts_repository.dart`) | `supabase/tests/rls_authorization_test.sql` (Test 1 & Test 8), `test/unit/post_privacy_test.dart` |
| **2. Friend-request initiators cannot accept their own requests (`SEC-02`)** | `friendships_update_recipient_only` policy (`USING (auth.uid() = addressee_id)`) + `enforce_friendship_transition` trigger (`00005`) | `FriendshipStatusesNotifier.requestOrToggleFriendship` & `acceptIncomingRequest` (`profiles_repository.dart`) | `supabase/tests/rls_authorization_test.sql` (Test 2B), `test/unit/post_privacy_test.dart` |
| **3. Only accepted mutual connections receive friends-only access** | `public.are_friends(user_a, user_b)` checks `status = 'accepted'` | `FollowedFriendsNotifier` only includes `FriendshipRelation.accepted` | `supabase/tests/rls_authorization_test.sql` (Test 2A & Test 3) |
| **4. Blocked users cannot access protected content** | `NOT public.is_blocked(auth.uid(), author_id)` in `posts_select_dual_layer` and `get_friends_feed` | `BlockedUsersNotifier` filters blocked authors from Feed, Explore, and Place Detail | `supabase/tests/rls_authorization_test.sql` (Test 4), `test/unit/post_privacy_test.dart` |
| **5. Users cannot modify another user's profile** | `profiles_update_own` policy (`USING (auth.uid() = id) WITH CHECK (auth.uid() = id)`) | `ProfileNotifier` updates `.eq('id', SupabaseService.currentUser!.id)` | `supabase/tests/rls_authorization_test.sql` (Test 5) |
| **6. Users cannot write posts on behalf of another user** | `posts_insert_own` policy (`WITH CHECK (auth.uid() = author_id)`) | `PostsNotifier.publishDrop` binds `author_id: SupabaseService.currentUser!.id` | `supabase/tests/rls_authorization_test.sql` (Test 6) |
| **7. Public content remains accessible per visibility rules** | `audience = 'public' AND is_quarantined = FALSE AND NOT is_blocked(...)` | `PostsNotifier.getPublicDrops` filters quarantined and blocked authors | `supabase/tests/rls_authorization_test.sql` (Test 7), `test/unit/post_privacy_test.dart` |
| **8. Account deletion executes via trusted backend operation (`TASK-09`)** | `public.delete_own_account()` `SECURITY DEFINER` RPC deletes `auth.uid()` without client `service_role` key (`00005`) | `SupabaseService.deleteOwnAccount()` called from `SettingsScreen._confirmDeleteOrResetAccount` | Verified in `00005_security_and_rls_remediation.sql` & `supabase_service.dart` |
