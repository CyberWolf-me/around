- **Audit & Remediation Date:** 2026-11-01
- **Scope:** PostgreSQL Row-Level Security (RLS) policies (`00001`–`00006`), `SECURITY DEFINER` / `SECURITY INVOKER` functions, Storage policies (`post-media`), client repository filters (`lib/`), and `supabase/tests/rls_authorization_test.sql`.
