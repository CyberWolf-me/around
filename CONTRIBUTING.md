# Contributing to Around

Welcome to the Around engineering team! We're excited to have you contribute to building the future of places-first social discovery.

## Quick Start
1. **Prerequisites**: Node.js v20+ and npm v10+.
2. **Setup**:
   ```bash
   git clone <repo-url>
   cd around
   npm install
   ```
3. **Run Local Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.
4. **Run Automated Tests**:
   ```bash
   npm test
   ```
5. **Type Check**:
   ```bash
   npm run lint
   ```

## Development Workflow
- Follow our [Collaboration Standards](docs/standards/COLLABORATION_STANDARDS.md).
- Create branches using `feat/<id>-<desc>` or `fix/<id>-<desc>`.
- Keep pull requests under 400 lines of code.
- Write unit tests for all business logic and privacy guards.
- Respect our [Code of Conduct](CODE_OF_CONDUCT.md).
